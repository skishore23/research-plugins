Support for Heimdall Policy Lab

Report bugs or ask questions at https://github.com/skishore23/research-plugins/issues.

Include the plugin name, version, host, Python version, command, expected behavior and a minimal synthetic example. Do not include credentials, private media, personal information, confidential policies or sensitive traces. Reports are public. There is no guaranteed response time.

Executable workflows require file/shell access and the documented Python dependencies. If your host cannot run the command, it can draft inputs but cannot report checks as executed. Include the exact error when requesting help.

Independent tools. Open source. October 2026.
